# T290

Material da disciplina **Resolução de Problemas com Grafos**.

## Estrutura

- `dataset/`: conjuntos de dados para exercícios e experimentos.
- `algs4-py/`: subconjunto em Python focado nos algoritmos de grafos usados na disciplina.
- `exs/und1/`: exercícios, imagens, listas e respostas da Unidade 1.
- `exs/und2/`: exercícios extraídos de bibliografia, PDFs de apoio e imagens da Unidade 2.
- `livros/`: livros e referências usados para extração e organização dos enunciados.

## Observações

- Arquivos de dataset acima de 100 MB não são aceitos pelo GitHub e estão no `.gitignore`.
- Para trabalhar com arquivos grandes, use armazenamento externo ou Git LFS.
- O pacote `algs4-py` foi reduzido ao subconjunto de grafos; módulos fora desse escopo foram removidos.
- Parte do material da Unidade 2 foi extraída de PDFs e consolidada em Markdown com imagens de apoio em `exs/und2/imgs/`.
