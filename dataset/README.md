# Datasets

Os datasets pequenos e médios estão disponíveis nesta pasta. Os arquivos abaixo não integram o repositório devido ao tamanho e devem ser baixados do site oficial do algs4:

- [`largeG.txt`](https://algs4.cs.princeton.edu/41graph/largeG.txt)
- [`largeDG.txt`](https://algs4.cs.princeton.edu/42digraph/largeDG.txt)
- [`largeEWG.txt`](https://algs4.cs.princeton.edu/43mst/largeEWG.txt)
- [`largeEWD.txt`](https://algs4.cs.princeton.edu/44sp/largeEWD.txt)
- [`largeUF.txt`](https://algs4.cs.princeton.edu/15uf/largeUF.txt)

Após o download, armazene os arquivos nesta pasta, preservando os nomes originais.
