# T290

Material da disciplina **Resolução de Problemas com Grafos**.

## Estrutura

- `dataset/`: conjuntos de dados para exercícios e experimentos.
- `algs4-java/`: subconjunto em Java focado nos algoritmos de grafos usados na disciplina.
- `algs4-py/`: subconjunto em Python focado nos algoritmos de grafos usados na disciplina.
- `exs/`: exercícios com resolução extraídos de bibliografia.
- `trabalhos/`: enunciados, orientações e materiais de apoio para trabalhos da disciplina.
